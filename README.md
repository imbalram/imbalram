## 📊 RAG & LLM Evaluation

I am particularly interested in measuring AI systems instead of relying only on subjective output quality.

| Metric | Why it matters |
|---|---|
| **Faithfulness** | Is the answer supported by retrieved context? |
| **Answer Relevance** | Does the response actually answer the question? |
| **Context Relevance** | Is the retrieved information useful? |
| **Recall@K** | Did retrieval find the relevant information? |
| **MRR** | How high did the first relevant result rank? |
| **Latency** | How quickly does the system respond? |
| **Token Usage** | How efficiently is the model being used? |
| **Cost** | Can the system operate economically at scale? |
